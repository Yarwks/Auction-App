# Auction App

A simple online auction app. Users can register, list items for sale, and bid on other people's items. Highest bid wins when the auction ends.

## What it does

- Sign up / log in
- List an item with a starting price and end time
- Browse and search active auctions
- Place bids (must be higher than the current price)
- Auction closes automatically once the end time passes, highest bidder wins


## Tech stack

- **Backend:** Django + Django REST Framework, SQLite database, JWT login
- **Frontend:** React (Vite), Tailwind CSS, Axios
